# Basic Terminology

## Client

A client is any device or software application that sends requests to a server to access resources or services. In everyday terms, your web browser acts as a client when it asks a web server to load a page. Clients initiate communication in the client-server model and rely on servers to respond with the requested data or functionality.

## Server
A server is a computer or software system that listens for requests from clients and responds by providing resources, data, or services. Servers can host websites, store files, manage emails, or run applications that many users access simultaneously. They are typically designed to be always available, handing multiple client connections at the same time.
