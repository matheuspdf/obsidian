## 1. Preparação do Ambiente

- Instalar o VirtualBox
- Instalar o Extension Pack
- Baixar as ISOs:
    - Windows Server 2019
    - Windows 10

## 2. Criação da VM do Servidor (Controlador de Domínio)

- Criar VM:
    - Tipo: Windows Server (64 bits)
    - RAM: mínimo 2 GB
- Criar disco com configurações padrão
### Configurações adicionais

- Clipboard e Drag and Drop: Bidirecional
- CPU: ajustar conforme disponível
- Rede:
    - Adaptador 1: NAT (internet)
    - Adaptador 2: Rede Interna
