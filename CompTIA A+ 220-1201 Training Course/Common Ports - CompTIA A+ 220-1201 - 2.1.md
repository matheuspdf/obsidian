# Port Numbers

_Números de Porta_

**Well-known port number** _Número de porta conhecido_ – Client and server need to match _– Cliente e servidor precisam coincidir_

**Important for firewall rules** _Importante para regras de firewall_ – Port-based security _– Segurança baseada em portas_

**A bit of rote memorization** _Um pouco de memorização mecânica_ – Becomes second nature after a while _– Vira algo natural depois de um tempo_

**Make sure you know port number, protocol, and how the protocol is used** _Certifique-se de saber o número da porta, o protocolo e como o protocolo é utilizado_


# FTP – File Transfer Protocol

_FTP – Protocolo de Transferência de Arquivos_

**tcp/20 (active mode data), tcp/21 (control)** _tcp/20 (dados em modo ativo), tcp/21 (controle)_ – Transfers files between systems _– Transfere arquivos entre sistemas_

**Authenticates with a username and password** _Autentica com usuário e senha_ – Some systems use a generic/anonymous login _– Alguns sistemas usam login genérico/anônimo_

**Full-featured functionality** _Funcionalidade completa_ – List, add, delete, etc. _– Listar, adicionar, deletar, etc._
