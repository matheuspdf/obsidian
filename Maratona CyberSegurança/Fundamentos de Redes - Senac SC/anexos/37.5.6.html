Objetivos

Neste laboratório, você usa a documentação da rede para identificar e corrigir problemas de comunicação de rede.

  • Usar várias técnicas e ferramentas para identificar problemas de conectividade.
  • Usar a documentação para orientar os esforços para solução de problemas.
  • Identificar problemas específicos de rede.
  • Implementar soluções para problemas de comunicação em rede.
  • Verificar a operação da rede.

Histórico / Cenário

Nesta atividade, você usará a documentação criada no Packet Tracer - Desafio de solução de problemas - Documentar a rede, para nortear os esforços de solução de problemas de rede.

Descobriu-se que a rede, com a qual trabalhou na atividade PT anterior, apresentou problemas de comunicação. Alguns hosts não conseguem executar ping em outros hosts e no servidor de internet. É seu trabalho determinar quais são os problemas e localizá-los e repará-los.

Problemas de rede podem existir em qualquer dispositivo. Certifique-se de verificar se há erros abrangendo:

  • Configuração de endereçamento
  • Ativação da interface
  • Roteamento
  • NAT

Instruções

As senhas para todos os dispositivos são VTY: cisco, Enable secret: class

Parte 1: Avalie a conectividade

Todos os hosts devem poder executar ping um ao outro e ao servidor da Internet. Determine se esse requisito é atendido. Caso contrário, identifique quais hosts e redes devem ser investigados mais detalhadamente.

Parte 2: Acessar dispositivos de rede

A partir dos hosts que têm problemas de comunicação, use as ferramentas ICMP para determinar onde na rede esses problemas podem estar localizados. Nos PCs host, acesse dispositivos na rede e exiba configurações e status operacional.

Parte 3: Reparar a rede

Depois de localizar os problemas, reconfigure os dispositivos para reparar o problema de conectividade. Use sua documentação da atividade anterior para ajudá-lo.
