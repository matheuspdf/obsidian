Objetivos

=  Usando comandos show do Cisco IOS

Histórico/Cenário

Os comandos show do Cisco IOS são usados amplamente quando se trabalha com equipamentos da Cisco. Nesta atividade, você usará os comandos show em um roteador localizado em um ISP.

Instruções

Parte 1: Conectar ao roteador Cisco 4321 ISP.

Nesta parte, você usará o software de emulação de terminal no ISP PC para se conectar ao roteador Cisco 4321.

a.  Clique em PC ISP.

b.  Clique na guia Desktop. Selecione Terminal. Revise a configuração do terminal e clique em OK para continuar.

c.  O prompt ISPRouter > indica que você está no modo EXEC do usuário. Pressione a tecla Enter se o prompt não tiver sido exibido.

Parte 2: Explore os comandos show.

Use as informações disponibilizadas por esses comandos show para responder às perguntas a seguir.

Etapa 1: Explore os comandos show no modo User EXEC.

a.  Digite show ? no prompt.

Pergunta:

Liste mais alguns comandos show que estão disponíveis no modo EXEC do usuário.

Área de Resposta

As respostas variam. Estes são alguns dos comandos show disponíveis: show cdp, show class-map, show clock

b.  Digite show arp no prompt.

Pergunta:

Registre o endereço MAC e o endereço IP listados.

Área de Resposta

As respostas podem variar. 0001.96CD.2501: 209.165.201.1, 000A.F3C7.5CD3: 209.165.201.5 e 0002.162C.67A7: 209.165.201.10

c.  Digite show flash no prompt.

Pergunta:

Registre a imagem do IOS listada:

Área de Resposta

ISR4300-universalk9.03.16.05.s.155-3.s5-ext.spa.bin

d.  Digite show ip route no prompt.

Pergunta:

Quantas rotas estão listadas na tabela?

Área de Resposta

2

f.   Insira show ip interface no prompt.

Pergunta:

De acordo com a saída show ip interface, qual interface está conectada?

Área de Resposta

GigabitEthernet0/0/0

g.  Digite show version no prompt.

Pergunta:

Qual pacote de tecnologia está ativo no roteador?

Área de Resposta

ipbasek9 e securityk9

h.  Insira show protocols no prompt.

Pergunta:

Quais protocolos estão ativos no roteador?

Área de Resposta

Internet Protocol routing is enabled. Line protocol is up for GigabitEthernet0/0/0.

i.   Digite show running-config no prompt.

Pergunta:

Qual é a saída?

Área de Resposta

ISPRouter> show running-config ^ % Invalid input detected at '^' marker.

Etapa 2: Explore os comandos show no modo EXEC privilegiado.

a.  Digite enable no prompt para entrar no modo EXEC privilegiado.

Pergunta:

Liste mais alguns comandos show neste modo.

Área de Resposta

As respostas variam. Alguns exemplos dos comandos show são: show aaa, show access-list, show file

b.  Digite show running-config no prompt.

Pergunta:

Qual é a saída?

Área de Resposta

A saída exibe as configurações atuais.
