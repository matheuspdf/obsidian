# ERRO:

`⚠ Setup notes: • Native installation exists but C:\Users\flopes\.local\bin is not in your PATH. Add it by opening: System Properties → Environment Variables → Edit User PATH → New →` `Add the path above. Then restart your terminal.`

1.  Abra **Variáveis de Ambiente**:
    - Pressione `Win + X` → **Sistema**
    - Clique em **Configurações avançadas do sistema**
    - Abra **Variáveis de Ambiente**
2.  Na seção **Variáveis do sistema**, clique em **Path** → **Editar**
3.  Clique em **Novo** e adicione:

```
   C:\Users\user\.local\bin
```

4.  Clique em **OK** em todas as janelas
5.  **Reinicie o PowerShell/CMD** (ou reinicie o computador)
