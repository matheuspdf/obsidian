# 1.2.1 Funções do Host

- **Host (Dispositivo Final / End Device):** Computadores, tablets ou smartphones conectados à rede que participam diretamente da comunicação.
- **Endereço IP:** Número único que identifica o host e a rede à qual ele pertence para fins de comunicação.
- **Servidores:** Computadores com software especializado para fornecer informações/serviços a outros dispositivos (ex: Servidor de E-mail, Servidor Web, Servidor de Arquivos). Um único servidor pode atender múltiplos clientes simultaneamente.
- **Clientes:** Softwares instalados nos hosts que solicitam e exibem dados do servidor (ex: Navegador web, cliente de e-mail como Outlook, Explorador de arquivos). Um PC pode rodar vários clientes ao mesmo tempo.
